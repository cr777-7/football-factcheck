# 核查规范与数据结构

## 足球事实的常见陷阱

- 球员身份：同名、译名、生日、国籍和代表队资格分开核对；俱乐部队与国家队不能混用。
- 身高/体重：记录来源和日期，来源测量值不同不一定是硬错；体重会变化。
- 球衣号码/球队：标明赛季、球队及截至时间，区分官宣、注册、租借、回归和实际出场。
- 首秀：区分成年队/青年队、正式比赛/友谊赛、首发/替补、俱乐部/国家队和不同赛事。
- 统计：区分自然年/赛季、生涯/单队、联赛/所有赛事、常规时间/加时、点球大战；助攻口径随数据商不同。
- 转会费：区分固定、浮动、总价、租借费、币种与是否官宣。媒体估价不是实际转会费。
- 奖项/纪录：核对颁奖年度、赛事范围、并列、性别/年龄组；“历史第一”需要覆盖范围证据。
- 赛果：主客队、两回合总比分、加时和点球大战分别记录；比赛时间使用明确时区。
- 引语：寻找原采访/发布会及上下文，核对翻译；找不到原文时不背书。
- 传闻：查报道存在、报道日期、记者/媒体可靠性及后续更新。“正在谈判”不等于成交。
- 预测/主观评价：如“史上最佳”“下轮一定赢”不能按可证实历史事实处理；评价中的数值前提可单独核查。

优先官方赛事报告、FIFA/UEFA/足协/联赛/俱乐部记录和原始采访；其次独立可靠媒体和注明口径的数据商。官方公关稿也不自动证明主观赞誉。多站转载同一通讯社算一个来源。来源冲突先查时间和口径，仍不能解决就标“证据不足”，说明冲突。

## claims.json（推荐模型输入）

```json
{
  "as_of": "2026-09-21",
  "claims": [
    {"id": "C001", "text": "阿根廷赢得2022年男子世界杯冠军。", "context": "用户文字第1句；成年男子国家队"}
  ]
}
```

日期为此次判断的适用日期，不等于所有断言事件发生日期。每个断言在 text/context 中写清自己的时间。ID 唯一。文本模式输入每个非空行一个 ID，复杂文章应先由助手拆分，不能把整段多重断言当一个事实。

## 模型审阅

每个模型输出 JSON：`{"claims":[{"id":"C001","assessment":"likely_true|likely_false|imprecise|uncertain|not_factual","reason":"...","suggested_correction":"...","search_queries":["..."],"candidate_urls":["..."]}]}`。

所有候选 URL 均未验证。脚本只检查返回格式、ID 覆盖和完成状态，不会自动把 likely_true 变成最终“正确”。

## report.json（网页验证后由助手编写）

```json
{
  "title": "足球信息核查报告",
  "checked_at": "2026-09-21T12:00:00+08:00",
  "as_of": "2026-09-21",
  "model_summary": "4个模型请求，3个完成全部断言；1个接口失败。详见 model-results.json。",
  "claims": [
    {
      "id": "C001",
      "text": "原断言",
      "status": "证据不足",
      "reason": "未找到足以支持或反驳的原始记录。",
      "correction": "暂不修改，等待证据。",
      "model_notes": "模型A支持，模型B不确定；均不是证据。",
      "sources": []
    }
  ]
}
```

`status` 仅允许：错误、瑕疵、正确、证据不足、非事实判断。

错误/瑕疵/正确至少附一个实际打开并核验的来源对象：
`{"title":"来源标题","url":"https://...","published_at":"未知或具体日期","accessed_at":"实际访问时间","evidence":"简短摘录或准确概括","verified":true}`。

验证标记必须由实际浏览产生，不是相信模型或脚本而填写。报告生成器只能检查字段，不能验证标记是否属实。证据不足可附相互冲突的来源并解释。

## 完整性与结论边界

导出时必须提供最初的 `claims.json`（`--claims claims.json`）。脚本逐项检查ID集合、原文与适用日期一致，并把原始context带入报告。遗漏项不得删去以制造“全部通过”，应保留并标为证据不足；完整覆盖仅表示覆盖了这份清单，最初拆解是否遗漏原稿仍需助手对照检查。

“未找到报道”不等于“事情没有发生”。“错误”需要与原断言同一时间和口径的直接反证；无法举证时标证据不足。“瑕疵”是可查证的语境或口径缺失，不包括个人措辞偏好。来源文字仅支持部分断言时拆分处理。涉及计算的比率/排名时保留原始数据、公式、分母和范围，使用代码或计算器复算，模型相同算式不算独立证据。

核查规则、裁判判罚等须使用事件当时生效的规则版本。引用摘录保持简短，报告保留证据事实与链接，不复制完整文章。
